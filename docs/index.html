What it fixes on its own

  • Numbers stored as text that silently drop out of totals
  • Formulas that drifted from the pattern the rest of the row uses — the classic wrong-total bug
  • SUM ranges that stop one row short and miss a value sitting right below
  • Lookup keys padded with spaces that break VLOOKUP/XLOOKUP matches

What it reports, but never silently changes

Broken references, hardcoded “plug” numbers inside formula blocks, duplicate keys, totals that disagree for business reasons. You get the exact cell, the evidence, and a plain-English suggestion — the decision stays yours.

Verified, not vibes

In a seeded test workbook with 13 planted defects (3 critical), SheetFix repaired 5 directly, cleared 8 findings on re-check — including the cross-foot failure that made row and column totals disagree — introduced 0 new issues, and reported the 5 judgment calls that remained. The underlying audit engine is deterministic and benchmarked on 2,700+ real-world workbooks.

How it works

  1. Open SheetFix, choose your .xlsx / .xlsm file
  2. Click Audit, Fix & Re-Check
  3. Get back a _fixed.xlsx, a fix log (old → new, with reasons), and the re-check report

Windows 10/11. No Excel or Python installation required. Your original file is never modified.
